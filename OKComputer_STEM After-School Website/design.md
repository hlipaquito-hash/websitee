# STEM Academy Website Design Style

## Design Philosophy

### Color Palette
- **Primary Colors**: Deep Navy (#1e3a8a), Clean White (#ffffff), Soft Gray (#f8fafc)
- **Accent Colors**: Bright Blue (#3b82f6), Warm Orange (#f97316), Success Green (#10b981)
- **Text Colors**: Charcoal (#374151) for headings, Medium Gray (#6b7280) for body text

### Typography
- **Display Font**: "Inter" - Modern, clean sans-serif for headings and navigation
- **Body Font**: "Inter" - Consistent typography system for optimal readability
- **Font Hierarchy**: Large bold headings (2.5rem+), medium subheadings (1.5rem), readable body text (1rem)

### Visual Language
- **Academic Excellence**: Professional, trustworthy design that conveys educational authority
- **Innovation Focus**: Clean, modern aesthetic with subtle tech-inspired elements
- **Accessibility First**: High contrast ratios, clear navigation, intuitive user experience
- **Youth Appeal**: Energetic but not childish, inspiring confidence in both students and parents

## Visual Effects & Styling

### Used Libraries
- **Anime.js**: Smooth animations for interactive elements and page transitions
- **ECharts.js**: Data visualization for student progress and program statistics
- **Splide.js**: Image carousels for student showcases and program highlights
- **p5.js**: Creative coding elements for STEM-themed background effects
- **Matter.js**: Physics-based animations for interactive learning demonstrations

### Animation & Effects
- **Hero Background**: Subtle particle system representing atoms and molecules
- **Scroll Animations**: Gentle fade-in effects for content sections (opacity 0.9 to 1.0)
- **Interactive Elements**: Hover effects with 3D transforms and shadow depth
- **Progress Indicators**: Animated progress bars for registration forms and course completion
- **Data Visualization**: Interactive charts showing STEM education benefits and outcomes

### Header Effect
- **Navigation Bar**: Fixed transparent header with blur backdrop effect
- **Logo Animation**: Subtle rotation and scale effects on hover
- **Menu Transitions**: Smooth slide-in animations for mobile menu
- **Active States**: Underline animations for current page indicators

### Background Design
- **Consistent Theme**: Subtle geometric patterns inspired by molecular structures
- **Gradient Overlays**: Soft blue-to-white gradients for section separation
- **Visual Depth**: Layered elements with proper z-indexing for 3D feel
- **Responsive Patterns**: Adaptive background elements that work on all screen sizes

### Interactive Components Styling
- **Form Elements**: Modern input fields with floating labels and validation states
- **Buttons**: Gradient backgrounds with hover lift effects and ripple animations
- **Cards**: Subtle shadows with hover elevation and border radius
- **Modals**: Backdrop blur with smooth scale-in animations
- **Tooltips**: Contextual help with fade-in animations and proper positioning

### Mobile Responsiveness
- **Touch-Friendly**: Minimum 44px touch targets for all interactive elements
- **Swipe Gestures**: Horizontal swipe navigation for program browsing
- **Adaptive Layouts**: Flexible grid systems that reorganize based on screen size
- **Performance Optimized**: Reduced animations and effects on mobile devices

### Accessibility Features
- **Color Contrast**: Minimum 4.5:1 ratio for all text elements
- **Focus Indicators**: Clear keyboard navigation with visible focus rings
- **Screen Reader Support**: Proper ARIA labels and semantic HTML structure
- **Motion Preferences**: Respect user's reduced motion preferences
